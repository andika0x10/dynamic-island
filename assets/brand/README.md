# Dynamic Island logo

The master logo is `public/brand/logo.png`, with a transparent background.
`assets/brand/app.ico` contains Windows icon sizes 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixels.
The host embeds the icon for its executable, window, and notification tray.
The installer uses the same ICO.

Created with the built-in image generation tool. Final prompt:

> Use case: logo-brand. Create a polished production app icon/logo for a Windows desktop utility named Dynamic Island, a black floating pill showing music, timers and battery. One centered logo mark only, no text or letters. A bold horizontal near-black capsule pill, with a short crisp pink audio waveform of three thick rounded vertical bars inset toward the right, and a small pale white circular activity dot inset on the left. Extremely simple confident geometric silhouette, flat vector-like treatment, precise smooth edges, strong proportions, legible at 16 to 32 pixels. The capsule should occupy about 86% of canvas width and 48% of canvas height, generously separated dot and bars, perfectly centered. Subtle thin medium-gray outline around the near-black capsule ensures visibility on dark Windows taskbar. Accent matches the existing app music pink #ff6482. No gradients, no glow, no 3D, no drop shadows, no surrounding tile, no mockup, no watermark, no checkerboard. Actual transparent background outside the capsule. Square high-resolution PNG.
